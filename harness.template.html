Read first. (1) A browser cannot call gw.fbr.gov.pk directly — FBR sends no CORS headers, so the reply is blocked and shows as “Failed to fetch”. Run node fbr-proxy.js (source on the Overview tab) and leave the Proxy URL below set to http://localhost:8787/proxy. (2) Your token is kept in this browser’s localStorage for convenience. Use a sandbox token here; production tokens belong in your server’s secret store. (3) DI Post, every POS call and every IMS call write real records. Only DI Validate is a dry run.
